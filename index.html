HISTORY

SENSOR LAB

01 · Heart Rate / Camera PPG

손가락의 혈액량이 심장 박동에 따라 달라지면서 카메라 영상의 색·밝기가 미세하게 변합니다. 이 반복 주기를 분석해 BPM을 추정합니다.

혈류 변화 → RGB 신호 → 주기 분석 → BPM

같은 러닝 속도라도 개인별 운동 부담은 다르므로 심박수는 운동 강도와 회복 상태를 보는 참고 지표입니다.

02 · Cadence / Accelerometer

휴대폰의 3축 가속도에서 반복 충격을 검출해 분당 스텝 수를 추정합니다.

a = √(ax² + ay² + az²) → peaks → SPM

휴대폰이 주머니나 암밴드처럼 몸과 같이 움직여야 합니다.

03 · Push-up / Virtual Proximity

전면 카메라에서 얼굴 박스를 검출하고, 얼굴 폭이 화면에서 차지하는 비율로 카메라와의 상대적인 거리를 판단합니다.

face width / frame width → FAR(UP) · NEAR(DOWN) → +1 rep

폰 위치마다 얼굴 크기가 달라지므로 처음에 UP과 DOWN을 한 번씩 보정합니다. DOWN → UP으로 돌아오면 1회를 카운트합니다.

04 · Privacy

영상은 서버에 업로드하지 않고 브라우저 안에서 분석합니다. 운동 기록은 이 브라우저의 Local Storage에만 저장됩니다.
